# ВАРИАНТ B — публикация через GitHub Desktop

Всё уже подготовлено: локальный git-репозиторий создан, коммит сделан.
Осталось только **опубликовать** — GitHub Desktop сделает авторизацию через
браузер (токен не покидает твой компьютер).

## Шаг 1. Установи GitHub Desktop

Скачай с https://desktop.github.com и установи. При первом запуске войди
в свой GitHub-аккаунт (откроется окно браузера — это безопасно).

## Шаг 2. Добавь локальный репозиторий

1. В GitHub Desktop: **File → Add local repository…**
2. В поле path укажи папку:
   ```
   C:\Users\gleb\Documents\MultiTool\HomeChats\Chat-28\french-miniapp
   ```
3. Нажми **Add Repository**.

Приложение покажет репозиторий с уже сделанным коммитом
«Французский Telegram Mini App». Сообщение «Local branch: master» — норм.

## Шаг 3. Опубликуй

1. Нажми кнопку **Publish repository** (по центру вверху).
2. Появится окно: сними галочку **«Keep this code private»** —
   репозиторий должен быть публичным (это бесплатный хостинг Pages).
3. Нажми **Publish repository**.

## Шаг 4. Включи GitHub Pages

После публикации:

1. На GitHub открой репозиторий → **Settings** (правый верхний блок).
2. Слева меню **Pages** (раздел Code and automation).
3. В «Build and deployment» → Source: **Deploy from a branch**.
4. **Branch**: выбери `master` (или `main`) → `/ (root)` → **Save**.
5. Подожди 1–2 минуты. Сверху появится адрес вида:
   ```
   https://твой-логин.github.io/french-miniapp/
   ```
   (имя берётся из названия репозитория, которое ты дал при Publish).

Открой этот адрес в телефоне или браузере — приложение работает.

## Как открывать из Telegram

Чтобы по кнопке открывалось в Telegram, сделай Mini App через @BotFather:

1. @BotFather → `/newbot` — создай бота (получишь токен).
2. `/setmenubutton` → выбери бота → **Send URL** → вставь ссылку с Pages.
3. Название кнопки — например «Учить французский».

Теперь у бота внизу будет кнопка, открывающая приложение на любом iPhone.

---
Совет: не коммить токены бота в этот репозиторий — приложение работает
без них (прогресс хранится на устройстве).
