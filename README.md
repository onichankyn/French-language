# 🇫🇷 Французский — Telegram Mini App

Мини-приложение для изучения французского, которое открывается прямо в Telegram
и работает на iPhone (и любом устройстве). Это **статичный сайт** (HTML + JS),
поэтому он бесплатно живёт на **GitHub Pages** — сервер и Python не нужны.

Всё хранится локально в браузере (`localStorage`): слова, уровни, серия дней.
Данные не покидают твоё устройство, интернет для сохранения не нужен.

## Что внутри

- 🧠 Карточки — интервальное повторение (уровни 0–5)
- ✏️ Упражнения — перевод в обе стороны
- 📚 Словарь — встроенный ~60 слов + свои добавления
- 🔤 Спряжения — регулярные глаголы (er/ir/re) и неправильные (être, avoir…)
- 💬 Диалоги — полезные фразы с переводом
- 📊 Прогресс — статистика и серия занятий

## Как опубликовать на GitHub Pages

### Способ 1 — через веб-сайт GitHub (просто)

1. Зайди на [github.com](https://github.com) и создай новый репозиторий
   (кнопка **New**). Название любое, например `french-app`. Оставь public.
2. Открой репозиторий → кнопка **Add file → Upload files**.
3. Перетащи сюда папку `french-miniapp` (файлы `index.html` и `manifest.webmanifest`
   — именно так, чтобы они лежали в корне, не во вложенной папке).
4. **Commit changes** — готово.
5. Открой **Settings → Pages** (слева, раздел Code and automation).
6. У **Branch** выбери `main` → кнопка **Save**.
7. Через 1–2 минуты появится адрес вида:
   `https://твой-логин.github.io/french-app/`

### Способ 2 — через GitHub Desktop (рекомендую, если будешь редактировать)

1. Установи [GitHub Desktop](https://desktop.github.com/) и войди в аккаунт.
2. **File → New repository…** — создай репозиторий.
3. Скопируй файлы `index.html` и `manifest.webmanifest` в эту папку.
4. **Commit to main**, затем **Publish repository** (верхняя кнопка).
5. **Repository → Repository settings…** или в вебе: **Settings → Pages**,
   Branch `main`, **Save**.

> Тест в браузере: просто дважды кликни `index.html` локально — приложение
> запустится и без Telegram.

## Как открывать из Telegram (Mini App)

Чтобы приложение открывалось по кнопке в Telegram, нужен бот:

1. Открой **@BotFather** в Telegram → `/newbot` → создай бота, получи токен.
2. У BotFather выполни команду `/setmenubutton`, выбери своего бота, нажми **Send URL**,
   вставь адрес с GitHub Pages (см. выше). Название кнопки — например «Учить французский».
3. Теперь у бота внизу появится кнопка, открывающая приложение на любом iPhone.

Можно также:
- задать **web app** как закреплённую кнопку → `/newapp` у BotFather;
- добавить **inline-кнопку** в сообщения бота (для этого нужен бот-бэкенд, см. раздел ниже).

## Связать с Python-ботом (необязательно)

Если хочешь, чтобы рядом работал и чат-бот (команды, напоминания), можно:
- в Python-боте (файл `french_bot.py`) добавить кнопку с `web_app=WebAppInfo(url=…)`,
  которая откроет это приложение из чата;
- приложение и бот могут хранить разные данные: в боте — в своей базе,
  в приложении — на устройстве. Для объединения потребуется небольшой сервер.
